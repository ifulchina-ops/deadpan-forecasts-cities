A program that writes one deadpan weather forecast for a city that does not exist: Blorptown gets 3 cm of sideways rain by noon, a high of 19 degrees, and a 90% chance the mayor denies the sky exists, citing a lack of evidence.

The entry is one line of 150 characters, inside the event's 1–160 character gate.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
